AI Play Games Publishing Tool

A personal command-line tool that publishes and localizes videos on a single YouTube channel.

What this tool does

This is a private command-line utility, run by one person on one personal computer. It automates the publishing chores for the YouTube channel AI Play Games, which posts videos about autonomous AI agents playing Minecraft.

Specifically, it does four things, always and only on videos owned by the channel owner:

  • reads back a video's own metadata to confirm a write succeeded;
  • updates the title, description, tags and localized metadata of that video;
  • adds that video to the channel owner's own playlist;
  • uploads subtitle tracks in 11 languages to that video.

The videos have no narration, so subtitles are the only way viewers who do not read English can follow them. Localizing every video into 11 languages by hand is what this tool exists to avoid.

Who can use it

No one but the channel owner. The tool is not distributed, not sold, has no sign-up, no user accounts and no web interface. The only Google account that can authorize it is the channel owner's own account. It cannot read, modify or access anyone else's YouTube data.

How it uses YouTube

The tool uses the YouTube Data API v3 through OAuth 2.0, authorized by the channel owner. By using this tool the channel owner agrees to the YouTube Terms of Service. Information about how Google handles data is described in the Google Privacy Policy.
