Privacy Policy

AI Play Games Publishing Tool · last updated 5 September 2026

Summary

This tool has exactly one user: the owner of the YouTube channel AI Play Games. It collects no personal data from anyone, has no other users, and shares nothing with any third party.

What data the tool accesses

Through the YouTube Data API v3, and only for videos owned by the channel owner, the tool accesses:

  • video metadata (title, description, tags, localizations) of the owner's own videos;
  • the owner's own playlists and their items;
  • caption (subtitle) tracks of the owner's own videos.

The tool does not access any other channel, any viewer information, any analytics, any comments, or any data belonging to another person. It does not read Google account profile information beyond what is required to complete the OAuth authorization.

What is stored, and where

Everything the tool stores is kept in local files on the channel owner's own computer. Nothing is uploaded to any server operated by the developer, because there is no such server.

  • OAuth refresh token — a single local credential file, used to reauthorize the tool without a new browser sign-in.
  • Video IDs and publish dates of the owner's own videos, used to know which video to update next.

No cookies, analytics, trackers or advertising identifiers are used. This page itself sets no cookies.

Who the data is shared with

No one. The data is never sold, rented, transferred or disclosed to any third party. It is not used to train any model. The only network destinations the tool contacts are Google's own YouTube Data API endpoints.

How long data is kept

The stored credential and video IDs are kept only as long as the tool is in use, and are deleted when the local files are deleted. There is no backup or archive elsewhere.

Revoking access

The channel owner can revoke this tool's access at any time from the Google Account permissions page at myaccount.google.com/permissions. Revoking access immediately and permanently stops the tool from reaching any YouTube data.

YouTube API Services

This tool uses YouTube API Services. By using it, the user agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Changes to this policy

If this policy changes, the revised version will be posted on this page with a new "last updated" date.
